# 智舍联动 SmartDorm Linkage —— 智能宿舍自动化规则编排 App

> 《鸿蒙高级应用开发工程师认证》期末大作业 · 主题三「联动实验室」
> 基于 HarmonyOS ArkTS / ArkUI 的智能宿舍规则编排与模拟联动应用（独立完成）

## 一、项目简介

面向智能宿舍场景，让用户自行编排「满足条件时自动执行设备动作」的联动规则，在可调的 Mock 环境中模拟运行，实时观察设备状态变化与执行日志，不依赖真实硬件或云平台。应用包含规则管理、环境模拟、设备面板、规则引擎计算、冲突优先级仲裁、手动接管、执行日志与数据持久化；开关动作成对配合，避免设备只开不关。

## 二、功能特性

- **5 类可控设备**：空调、台灯、窗帘、风扇、加湿器。
- **4 项可调模拟环境**：室温(℃)、光照(lux)、人体在场、湿度(%)。
- **7 条预置规则**（阈值均可在界面编辑）：

| 规则 | 触发条件 | 执行动作 | 优先级 |
|---|---|---|---|
| R1 高温制冷 | 室温≥30℃ **且** 在场（双条件） | 空调切制冷26℃、关闭风扇 | 3 |
| R2 暗光补光 | 光照<100lux **且** 在场 | 打开台灯 | 2 |
| R3 低温制热 | 室温<16℃ | 关闭风扇、空调切制热 | 2 |
| R4 无人兜底 | 无人在场 | 关闭全部设备 | 4 |
| R5 干燥加湿 | 空调制热中 **且** 湿度<40% | 打开加湿器 | 1 |
| R6 光照充足关灯 | 光照≥100lux | 关闭台灯 | 1 |
| R7 湿度充足关加湿 | 湿度≥40% | 关闭加湿器 | 1 |

> R2↔R6、R5↔R7 为成对配合规则：暗光开灯、光照充足自动关灯；干燥开加湿、湿度回升自动关加湿。

- **规则管理**：新增、编辑（原阈值自动回填）、启用/停用、删除；删除前弹出确认框，确认后才移除，防止误删。
- **条件判断**：支持温度、光照、湿度的「高于(≥)」「低于(<)」两类比较，可组合在场判定。
- **规则引擎真实计算**：按实际环境输入逐条判定触发，输出动作序列。
- **冲突优先级仲裁**：多规则命中同一设备时按优先级降序执行，冲突动作丢弃并在日志注明。
- **手动接管**：手动操作的设备被锁定，规则不再强行改写；点「解锁」交还规则管理。
- **执行日志**：记录时间、触发规则、命中条件、设备动作与执行顺序，可清空。
- **数据持久化**：规则、设备设置、环境快照、空调模式、执行日志均存 Preferences，杀进程重启后恢复。

## 五、运行方法

1. 用 DevEco Studio 打开本工程根目录，等待同步完成。
2. 顶部设备选择本地模拟器（Emulator）或已连接真机。
3. 运行配置选 **entry**，点绿色三角启动应用。
4. 在「环境」页调节温湿度/光照/在场，点底部「运行联动」，在「设备」页看设备变化，「日志」页看执行记录。

### 运行单元测试

1. 运行配置新建 **Instrument Test**（OHOS Test），Module 选 entry，Package 指向 `entry/src/ohosTest/ets/test`。
2. 选该配置运行，模拟器上执行，测试结果窗口显示 8 条用例全部通过。
